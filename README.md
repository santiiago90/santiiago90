## 🚀 Featured Projects

### 🌿 [Aromatic Herbs Cultivation Management](https://github.com/santiiago90/Aromatic-Herbs-Cultivation-Management)

A full-stack web application developed as part of the **Server-Side Programming** course at UBI.

The platform was designed to manage aromatic herb cultivation and includes:

- REST API built with **Node.js** and **Express**
- **MongoDB** database with Mongoose
- Authentication using **JWT** and **bcrypt**
- Role-based permissions
- Complete CRUD operations
- Automatic environmental alerts
- Audit logs for user actions
- API documentation with **Swagger / OpenAPI**
- Responsive frontend built with **HTML, CSS and JavaScript**

---

### 🔢 [Numerical Systems with Flask](https://github.com/santiiago90/Sistema-Numerico)

A web application developed in **Python and Flask** as part of the **Web, Mobile and Cloud Ecosystem** course at UBI.

The project combines web development with numerical systems, implementing the underlying algorithms manually to better understand how different numerical representations work.

The application includes:

- Conversions between **Binary, Decimal and Hexadecimal**
- Binary arithmetic operations
- Hexadecimal arithmetic operations
- **Gray Code** table generation
- Custom conversion algorithms implemented in Python
- Input validation
- HTTP form processing with **Flask**
- Dynamic templates using **Jinja2**
- Web interface built with **HTML and CSS**

---

### ✅ [Task Manager](https://github.com/santiiago90/task-manager)

A simple task management application that started as a REST API and later evolved into a complete web interface.

Built with:

- **Node.js**
- **Express**
- **MongoDB**
- **Mongoose**
- HTML, CSS and JavaScript

The application supports complete CRUD operations, task completion and a weekly calendar interface for organizing tasks.
